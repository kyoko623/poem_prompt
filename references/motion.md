# 图生视频动效：实况图 / 2–3 秒短视频

适用场景：成图已经定下来，要让画面"按意境动起来"，做抖音实况图或短视频。实测平台：Seedance 2.5（即梦）。

## 一、原则

1. **镜头固定**：开头就写"固定机位，镜头完全不动"。推拉摇移会破坏"会呼吸的照片"的感觉，实况照片的封面也会和视频对不上。
2. **大形体不动，只让空气动**：雾、风、水、落叶、衣袂、光的轻微闪动。点景人物只动衣袂和头发，不走、不转身。
3. **幅度要写得看得见**：用"清楚地、明显地、一点点"来写。通篇"极慢、极静、极细微"会让模型几乎不动。
4. **每个动作写方向和终点**：落叶"向左下飘落""滑出画面右边"；雾"向右流动""向上漫"。
5. **小物体写尺寸**：叶子写"只有酒杯一半大"，不写就会画到两倍大。模型爱让叶子飞上天，写了"始终贴着地面，不飞起来"也不一定管用——能接受就接受，不能就换一个动作。
6. **不写"天暗下去 / 入夜"**：模型会把它执行成整张画面一起压暗，像在调色软件里拉低曝光。要表现时间流逝，交给结霜、落叶、雾的流动，并写"整体亮度和色调始终保持不变，不要变暗"。
7. **首尾帧怎么放**：
   - 首尾帧放同一张图：视频会回到起点，可以无缝循环，但动作幅度会被压小。适合风、雾、水这类来回的动。
   - 只放首帧：动作能往一个方向走（结霜、叶子离开），首尾接不上。实况照片按住只播一遍，本来就不需要循环。
8. **负向写在句尾**：不要镜头运动、不要人物动作（或不要出现人物）、不要新增物体、不要改变颜色和构图、不要出现文字。
9. **视频里不带诗句**：先让画面动，字另外叠，免得被 AI 扭曲。

## 二、模板

```
固定机位，镜头完全不动。<这一镜的时间与风>：<动作 1：什么、朝哪、到哪、多明显>；<动作 2>；<动作 3>。<大形体和点景的哪些部分保持不动>。<节奏：缓慢连续 / 看得见的时间流逝>。不要镜头运动，不要<人物动作 / 出现人物>，不要新增物体，不要改变颜色和构图，不要出现文字。
```

## 三、范例：杜甫《登高》四镜（Seedance 2.5，出片约 4 秒，后期压到 3 秒）

**镜一 · 天高鸟回**（首尾帧同图）

```
固定机位，镜头完全不动。高空的大风持续吹过：崖顶几棵古树的枝条被风吹得轻轻摇晃，崖边的薄雾被风扯成长条，缓缓向右流动、散开；高空的孤鸟张着翅膀乘风滑翔，缓慢地盘旋小半圈，几乎不扇翅；江面细小的波纹轻轻闪动。崖壁、白沙渚、远山完全静止。整体动作缓慢、克制，像一张会呼吸的照片。不要镜头推拉摇移，不要新增任何物体，不要改变画面颜色和构图，不要出现文字。
```

**镜二 · 落木长江**（首尾帧同图）

```
固定机位，镜头完全不动。风一阵阵吹过崖顶：古铜色的枯叶不断从树上被卷下，斜斜地向左下方飘落，远处的落叶纱幕缓缓流动；长江的长浪从崖脚后方横向向左涌动，江面那条逆光亮带随水波闪烁；江心的礁石纹丝不动，四周的白色水花轻轻翻起又落下。崖壁完全静止。动作缓慢、连续，落叶是真实的枯叶，不是发光的粒子。不要镜头运动，不要新增物体，不要改变颜色和构图，不要出现文字。
```

**镜三 · 独立高台**（首尾帧同图）

```
固定机位，镜头完全不动。老人拄杖静立，身体不动、不走、不转身，只有衣袂和稀疏的头发被风吹得轻轻飘动；几片古铜色的落叶从画面中缓缓飘过；崖脚的藕荷色雾气缓慢地横向流动；远处层层山岭静止，天边那条光线极轻微地明暗呼吸。动作极慢、极轻，像时间几乎停住。不要镜头运动，不要人物动作，不要新增人物和物体，不要改变颜色和构图，不要出现文字。
```

**镜四 · 霜台空杯**（只放首帧，第 3 版）

```
固定机位，镜头完全不动。整体亮度和色调始终保持不变，天空、崖体和石台都不变暗，不要天黑，不要改变曝光。画面里只有这几处在动：石台上的白霜从石缝边缘慢慢结出，一点点向中间的空酒杯蔓延，能清楚看到霜在生长；一片很小的古铜色枯叶（只有酒杯一半大）被风吹着，贴着霜面从左向右横向滑过，擦过空杯旁边，滑出画面右边，始终贴着地面，不飞起来；崖身中部那一带冷雾清楚地向右流动，谷底的薄雾缓缓向上漫；天边那一线琥珀色余光保持原样，只有极轻的闪动。空酒杯纹丝不动，杯里始终是空的。不要镜头运动，不要出现人物，不要新增其他物体，不要改变构图和颜色，不要出现文字。
```

**镜四的迭代**
- v1（首尾帧同图 + 通篇"极慢、极细微"）：几乎不动；后期再做正放倒放，又抵消掉一半。
- v2（只放首帧 + "余光暗下去" + 叶子）：动起来了，但整张画面一起变暗、后半段越暗越快，像拉曝光；叶子有酒杯两倍大，还飞上了天。
- v3（锁住亮度 + 结霜 + 小叶子贴地 + 雾）：亮度稳定（平均亮度 108 ± 0.4），杯脚结霜清楚、叶子擦着杯边滑过、雾在流动。叶子最后仍被卷起，杯脚的霜偏厚——可以接受。

## 四、做成苹果实况照片（`scripts/make_live.py`）

- **依赖**：macOS、ffmpeg、`pip install makelive`（建议装在独立虚拟环境）。
- **命令**：

  ```bash
  python3 scripts/make_live.py --pairs 原图1.png 视频1.mp4 原图2.png 视频2.mp4 \
    --names 01_xx 02_xx --out 输出目录 --seconds 3 --fit speed --aspect 3:4 --still video
  ```

- **`--fit`**：首尾能接上的用 `speed`（整体加速到目标时长，保住循环）；首尾接不上又想循环的用 `pingpong`（正放一半再倒放）；只想截取用 `trim`。
- **`--still video`**：封面取成品视频的第一帧，按住播放时不跳（原图和生成视频的首帧常有色差）。
- **`--aspect 3:4`**：抖音图文里显示更大；上下用画面缩小、模糊、放大后的色块补边，不会出现放大的人影。
- **检查**：`from makelive import is_live_photo_pair` 返回一个 ID，就说明配对成功。
- **导入「照片」**：把 jpg 和 mov 一起导入，8 个文件合成 4 项就说明都是实况照片：

  ```applescript
  tell application "Photos"
    import {POSIX file "/路径/01.jpg", POSIX file "/路径/01.mov"} skip check duplicates true
  end tell
  ```

- **到手机**：开了 iCloud 照片会自动同步；没开就在「照片」里选中后隔空投送（从「照片」App 里投送才保留实况）。
- **发抖音**：图文模式按顺序选，确认实况是开着的。
