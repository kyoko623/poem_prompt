# 方法与原则

## 一、好图的八个要素

| 要素 | 画面里的样子 | 写进提示词的方法 |
|---|---|---|
| 大形体 | 一两块巨大形体占画面一半以上，贴着或顶到画框边、被裁切 | 写体量占比、顶到哪条边、被怎样裁切；这一段写得最长 |
| 明暗结构 | 形体是深色大暗块；天、雾、水是亮的 | 写"形体深、空气亮"，暗部有颜色、不是死黑 |
| 一条最亮的线 | 一道白沙、一线水天亮光、一条崖顶逆光边，落在最暗处前面 | 写那条线在哪、多细、多亮 |
| 光从一角斜入 | 一角的亮雾照亮形体顶部，形体脚下埋在发光的雾里 | 光源藏在一角的雾里；形体顶边受光、脚下有雾 |
| 层层剪影 | 远处的崖、岭、岸一层比一层淡 | 写 2–3 层剪影、一层比一层淡、能认出轮廓 |
| 单色相、明度拉满 | 一个颜色从深调一直到近白 | 写一个色相从深到浅的阶梯 |
| 极小点景 | 人、鸟、礁石、空杯，不到画面高度的 2%，落在大暗块下的亮处 | 点景放在大形体脚下的亮处 |
| 平静的大面 | 水面、地面或天空大面积平、亮、低纹理 | 写大面积低纹理的亮面 |

## 二、意境 → 画面关系（本 skill 实测过的例子）

| 诗句 | 诗眼 | 画面关系 | 故意没画什么 | 做法 |
|---|---|---|---|---|
| 欲买桂花同载酒，终不似，少年游 | 终不似：东西都在，回不去了 | 断 / 续 + 远 | 没画桂树、船和酒宴 | 一座巨大石矶横着伸进江里突然断开，人站在断口；对岸旧楼只剩光雾里的轮廓 |
| 君不见黄河之水天上来，奔流到海不复回 | 天上来、不复回 | 来 / 去 + 大 / 小 | 没画瀑布 | 一侧深赭黄土崖压住画面，远方水天之间一条亮线，河像从天上流来 |
| 风急天高猿啸哀，渚清沙白鸟飞回 | 天高风急、无处落脚 | 大 / 小 + 盘旋 | 没画猿 | 一侧石青巨崖，崖顶古树被风扯斜；大片高空里一只盘旋的孤鸟；江心一弯白沙最亮 |
| 无边落木萧萧下，不尽长江滚滚来 | 落不完、流不尽 | 两种运动同在 | —— | 落叶斜斜向下铺满天空，江水横向奔流；江心一块不动的礁石 |
| 万里悲秋常作客，百年多病独登台 | 独、万里 | 大 / 小 + 远 | —— | 巨崖顶的石台上一个拄杖老人，面前层层远去的山岭 |
| 艰难苦恨繁霜鬓，潦倒新停浊酒杯 | 人老酒停 | 有 / 无 | 没画人 | 霜台上只剩一只空杯，天边一线将熄的余光 |

## 三、常见套路（默认不用）

这些是国风意境图里用滥的现成画面，一用就"像见过"：

- 水面上一叶孤舟 + 一个极小的人
- 一棵大树从画面一侧压进来
- 高调白雾留白、几乎全白的画面
- 白衣小人
- 瀑布 + 崖壁
- 两侧山崖夹成一道门洞
- 芦苇海、雪景、整面枫林这类一眼国风的现成场景

只有当它正是这首诗独有的意象时才用（比如诗里本来就写了孤舟）。

## 四、失败对照（实测）

| 出图现象 | 提示词里的原因 | 改法 |
|---|---|---|
| 灰白发闷 | 写了玉白、淡银灰、中低对比、微凉 | 换成明确色相，提明度 |
| 像写实照片 | 缺绘画感锚点 | 写数字绘景 + "远处概括成柔和色块" |
| 像扁平插画 | 写了 illustrative、轻写意 | 删掉，强调真实质感 |
| 峡谷、画面中央一个亮洞 | "临江断崖"加"光从后面穿过" | 大形体只放一侧，光源放到画框外 |
| 满屏光点、东西发光 | 叠加发光修饰，写了"唯一金色" | 删掉所有发光修饰 |
| 游戏截图、黑边乱码字 | cinematic、real-time、画幅比例写进正文 | 删掉，比例在平台里选 |
| 像极简摄影、阴郁 | 元素太空，明度压暗 | 放大主形体，提亮空气，加雾层与剪影 |
| 像加了滤镜、差点意思 | 没有深色大形体，全图一种亮色 | 加大形体，拉开明度 |
| 装饰性卷云 | 写了"勾云法" | 写有体积、有明暗的自然云体 |
| 人太大 | 模型会把写的比例放大 3–4 倍 | 写 1%–2%，放在大形体脚下 |
| 远景被吞掉 | 只写了"极淡" | 写"能认出 X 的轮廓，不清晰、不抢主体" |
| 分镜几张颜色一样 | 风格锁把色调也锁了 | 每镜换色相，大形体颜色跟着光变 |
